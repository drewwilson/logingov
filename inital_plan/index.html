Key architectural decision — Better Auth + Durable Objects for sessions
Better Auth handles session lifecycle with Cloudflare KV as secondary storage for fast distributed reads. Each active auth flow is backed by a Durable Object co-located at the nearest CF region, eliminating cross-region lookups on the hot path. Token validation (JWKS lookup via KV + DO session check) never touches PlanetScale — the database is only hit on login, registration, and account mutations.
